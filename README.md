# 高性价比饮食指南 · 在线阅读页

一个单文件 HTML 阅读页，把《高性价比饮食指南》的各节条目渲染成可搜索的页面。手机上打开就能看，不用装任何东西，断网也能读。

**在线阅读：** <https://你的用户名.github.io/how-to-eat-better/>（把仓库设置里的 Pages 打开即可：Settings → Pages → Deploy from a branch → main / root）

## 这是什么

一本按「性价比」排序的饮食书。每条建议写清三件事：**花掉什么**（钱、时间、毅力）、**换回什么**（寿命、健康指标、金钱、安全）、**证据多硬**（A/B/C 三级）。来源只引期刊论文、官方机构报告和政府部门通报，少数写"卷期待核实"的是数字待逐条核对。

它参考了 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（《高性价比人生指南》）的写法：同样是「成本 × 收益 × 证据等级」的条目制，同样是单文件、零依赖、手机可读的阅读页。两本书互补：那本讲整个人生，这本专讲一日三餐。

**本项目从未发行、也不会发行任何代币或数字资产。**

## 这本书想回答的问题

- 同样的预算，怎么吃得更像《中国居民膳食指南》？
- 厨房里最值得改造的三件事是什么？（盐、油、抽油烟机）
- 哪些"养生说法"其实没有证据？（过午不食、酸碱体质、食物相克、骨头汤补钙……）
- 哪些食物真的会吃死人？（毒蘑菇、河豚、酵米面、自制药酒……）
- 孕妇、孩子、老人、糖尿病人、肾病患者，分别该改什么？

## 页面特性

页面结构与交互严格对齐 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 的阅读页：

- **零外部资源**：没有 CDN、没有字体外链、不请求任何数据，断网也能读，微信里能直接传
- 固定顶栏（logo + 搜索 + README/GitHub 入口 + 明暗主题开关）+ 左侧筛选侧栏 + 右侧内容区
- 逐条卡片：条目标题、证据等级徽章（A/B/C）、性价比档（极高/高/一般）、成本标签（钱/时间/毅力）、争议与「含待核实」标记
- **「说人话」高亮块**——把研究里的数字翻成日常说法，页面上做得最显眼
- 左侧筛选：章节单选；性价比、证据等级、花钱、花时间、要毅力组内多选、组间且；「只看标了争议的」「只看有待核实的」开关；筛选状态写进 URL，可直接分享
- 全站关键词搜索（结果高亮、按 `/` 快速聚焦）
- 正文里「见第 X 节第 Y 条」可点，点一下滚到那条并闪一下底色
- 手机端：侧栏变抽屉、搜索快捷键隐藏；明暗主题跟随系统，可手动覆盖并记住
- 支持直接打印（Ctrl/Cmd+P）

改过页面交互脚本（`build.py` 里内嵌的 CSS/JS）后，跑一遍回归测试：

```

```

## 怎么贡献

正文按节拆成 13 个文件放在 `book/`，一条建议长这样：

```
### 1. 把家里的盐换成低钠盐（高危人群尤其）
<!-- 成本标签: 钱=少 时间=0 毅力=否 收益=大 口径=死亡率 -->
- 成本：一袋比普通盐贵几元。口味几乎不变。
- 说人话：得过中风或 60 岁以上有高血压的人，把盐换成低钠盐，五年内死亡的概率低约 12%，中风低约 14%。
- 收益：一项把人按村随机分组的试验，中国 5 省 600 个村、20995 人，跟踪 4.74 年……
- 证据等级：A
- 来源：Neal B 等 (2021). Effect of Salt Substitution on Cardiovascular Events and Death. NEJM. <https://doi.org/10.1056/NEJMoa2105675>
- 备注：肾功能不全的人换盐前先问医生。
```

字段顺序固定：成本 → 说人话 → 收益 → 证据等级 → 来源 → 备注。成本标签里：钱=0/少/多，时间=少/中/多，毅力=否/些/是，收益=大/中/小，口径=任意短词。性价比档由脚本按「收益量级 + 三项成本」自动算出。

**写新条目的三条规矩：**

1. 来源只引原始文献（期刊论文附 DOI 或官方链接）或官方文件；拿不准的数字标「待核实」，别硬编。
2. 「说人话」只用「收益」栏里已有的数字，不添新数，写成"哪些人、低几成"这样的日常说法。
3. 有争议的写在「备注」里，把反方证据列出来——本书不追求政治正确，追求可核对。

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查，出处是荟萃分析、大型队列或随机分组试验（RCT）；法律政策类指引到法条或官方文件原文 |
| B | 有研究支持但说不出确切数字，或只有小样本、单项研究 |
| C | 作者经验、通行做法或官方科普，没有直接研究文献 |

**A 级只说明「有具体数字、出处可核」**，不说明一定是因果：写着「只记录、不分组」的是观察性研究，分不清是这件事起了作用还是做这件事的人本来就更健康；写着「随机分成两组」的才能说因果。

## 性价比口径

证据等级回答「数字可不可信」，性价比回答「值不值得做」。每条按三项成本（钱、时间、毅力）加收益量级（大/中/小）自动归档：

- 好处大、三项成本全零 = **极高**
- 好处大、成本不高，或好处中等、成本为零 = **高**
- 其余 = **一般**

**这一档是作者自己的判断，不是证据**，按本书标准它本身只算 C 级。一条可以证据 A 级、性价比一般（处方减肥药），也可以证据 C 级、性价比极高（把含糖饮料换成水）。「一般」不等于不该做。
